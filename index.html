EBS Rclone Backup

EBS Rclone Backup is a private backup utility used to securely transfer backup files to Google Drive using rclone.

The application is intended for internal administrative use and is not offered as a public service.

Google Drive Access

Google Drive access is used exclusively to store, verify, manage, and maintain backup files belonging to the authorized Google account.

The application does not sell or share Google user data with third parties.
